# Queueing Theory Player v0.1.0

First versioned release of the development → testing queue model.

- Development and testing capacities fluctuate independently. Enter the Gaussian
  mean and standard deviation for each department in the player.
- Gaussian draws are rounded to whole features and negative counts are set to
  zero. The player displays the effective count mean and standard deviation.
- Follow features through arrivals, the FIFO testing queue, and completed tests;
  inspect backlog, unused testing capacity, waiting time, and development spend
  tied up in waiting features.
- Play, pause, step, adjust speed, or jump to a working day. Parameter comparisons
  reuse the same independent standard-normal draws.
- Defaults: 500 working days; development mean 10 / SD 2; testing mean 10 / SD 2;
  seed 42; development cost €1,000 per feature.

## Scope

This is an illustrative daily batch model with independent days, equally sized
features, FIFO testing, and arrivals before testing. It has no rework, feedback,
correlation, variable feature effort, or sales process. The four inputs describe
the underlying Gaussians; rounding and clamping can change their effective
means. The displayed path is one reproducible realization, not an ensemble
prediction. This release establishes the starting point for further modelling.

When writing about it, cite **Queueing Theory Player v0.1.0 — fluctuating
development and testing capacities** and link to the fixed player or release.
